# Оригиналы фото из Instagram

Сюда кладём исходные файлы из постов @under.lavka. Имя файла должно совпадать с `slug` в `../sources.json`.

После этого запусти из папки `under-demo`:

    python3 tools/optimize_images.py

Скрипт пересоберёт WebP 480/960 и обновит `sources.json`. В `post_url` впиши ссылку на пост.

Сейчас здесь лежат временные кропы со скриншотов. Их нужно заменить оригиналами.
