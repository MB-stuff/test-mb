# Grand Simulacre — настольная версия (Windows)

Обёртка Electron вокруг собранной игры `hotel/dist/Hotel.html`. Внутри тот же Chromium, на котором игра проверялась в браузере, поэтому WebGL, тени, захват мыши, звук и настройки работают так же.

## Что добавлено по сравнению с браузером

- Запуск сразу во весь экран; **F11** или кнопка «В окне / Во весь экран» в меню — переключение.
- Кнопка **«Выйти»** в меню (только в настольной версии).
- Музыка играет уже на титульном экране, без первого клика.
- Своя иконка (полосатое солнце) и название окна «Grand Simulacre».
- Настройки (громкость, пиксели, тени, прорисовка, интерфейс) хранятся в профиле программы — `%APPDATA%\Grand Simulacre` — и не зависят от браузера.
- Ссылки «источник» у картин открываются в обычном браузере.
- Запускается только одна копия: повторный запуск поднимает уже открытое окно.

## Сборка

Нужен Node.js 18+. Сначала собрать саму игру, потом обёртку:

```bash
cd hotel && npm install && npm run build
```

```bash
cd desktop && npm install && npm run dist
```

Готовый файл: `desktop/dist/Grand Simulacre 1.0.0.exe` — переносной, запускается без установки (при первом запуске распаковывается во временную папку, это несколько секунд).

Установщик с ярлыком на рабочем столе и в меню «Пуск»:

```bash
cd desktop && npm run dist:setup
```

Запустить без сборки exe (для проверки, на любой системе):

```bash
cd desktop && npm start
```

Сборку можно делать и на Linux/macOS: иконка вшивается в exe библиотекой `resedit` (скрипт `scripts/set-icon.cjs`), Wine не нужен.

## Предупреждение Windows

Файл не подписан сертификатом, поэтому при первом запуске SmartScreen покажет «Windows защитила ваш компьютер». Нажать «Подробнее» → «Выполнить в любом случае». Убрать предупреждение можно только платным сертификатом подписи кода.
