# Элизиум

Кодекс и набор механик для бродилок от первого лица в браузере: three.js, процедурная графика и звук, один офлайн-файл HTML (по желанию ещё и exe).

Элизиум собран из опыта проекта **Grand Simulacre**, пустого отеля в малиновой пустыне. Каждое правило ниже — ответ на ошибку, которую там уже нашли и исправили. Цель простая: следующую игру не строить с нуля, а начинать с работающей основы и сразу заниматься миром, а не стенами, светом и мышью.

Здесь три вещи:

1. **Набор модулей** (`src/core/`): мир, двери, игрок, свет, солнце, отсечение, звук, ввод, интерфейс, автопроверки. Модули независимы от конкретной игры.
2. **Образец** (`src/demo/`): павильон, на котором видна каждая механика. С копии этой папки начинается новый проект.
3. **Этот кодекс**: как всё устроено, какие числа работают, какие грабли уже собраны.

---

## 0. Новый проект за десять минут

```bash
cd elysium && npm install
```

1. Скопируй `src/demo` в `src/<имя>`.
2. В `src/<имя>/game.json` впиши название, подзаголовок, описание и имя выходного файла.
3. В `src/<имя>/main.js` замени функцию `build()` своим миром, а в `createGame({…})` поставь точку старта, габарит здания и солнце.
4. Собери проект:

```bash
node build.mjs <имя>
```

5. Проверь сборку:

```bash
node tools/qa.cjs dist/<Файл>.html
```

6. Получившийся `dist/<Файл>.html` открывается двойным кликом и работает без сети.

Чтобы собрать exe, в `desktop/package.json` поменяй `productName` и `appId`, затем:

```bash
cd desktop && npm install && npm run dist
```

Отладочные параметры адреса:

| Параметр | Что делает |
|---|---|
| `?autostart=1` | сразу в игру, без меню |
| `&x= &y= &z= &yaw= &pitch=` | старт в точке и с нужным взглядом |
| `?qa=1` | всё видно; в консоли работают `__qa()`, `__qaCoplanar()`, `__qaGaps()` |
| `?shot=1` | можно делать скриншоты холста |
| `?shadows=0/1` `?draw=0/1/2` `?pixel=0/1` | режимы графики |
| `?ao=0` / `?ao=2` | выключить затенение углов / показать только его карту |

В консоли доступен `window.__game`, а `__game.act(/подпись/)` нажимает ближайшее действие с такой подписью.

## 1. Принципы

- **Один файл.** Код, текстуры и звук собираются в один HTML. Игру можно переслать одним файлом, она живёт без сервера. Картинки, если есть, кладутся внутрь как base64.
- **Всё процедурно.** Текстуры рисуются на canvas, звук синтезируется WebAudio, музыка генерируется. Нет ассетов — нет проблем с лицензиями, весом и загрузкой.
- **Метры и этажи.** 1 единица = 1 метр, Y вверх. Этаж `L` занимает высоты `[L·FH, (L+1)·FH)`, у каждого этажа своя группа. Видны свой этаж и соседние.
- **Мир — данные.** Стены, зоны, лампы, звуки, двери, окна регистрируются в общем состоянии `W`. Дальше системы (свет, звук, отсечение, проверки) работают по этим спискам, ничего не зная о конкретной игре.
- **Сначала конструкция, потом отделка.** Сперва несущая геометрия: стены с проёмами, полы, потолки. Потом мебель с метками «на чём держится», в конце свет и звук. Автопроверки после каждого шага.
- **Ничто не совпадает.** Две видимые поверхности никогда не лежат в одной плоскости. Это главный источник «мигающих текстур» (раздел 5).
- **Ничего не включается само.** Всё, что игра спрятала (погашенный ореол, пятно под задёрнутой шторой, ещё не открытый проход), помечается `userData.off`, и ни одна система не имеет права показать это снова.
- **Проверять глазами и скриптом.** Скриншот из точки показывает то, что скрипт не видит, а скрипт ловит то, что глаз пропустит. Обязательно оба (раздел 18).

## 3. Цикл кадра

Порядок не случаен:

1. **Ввод → игрок.** `updatePlayer(dt)`. `dt` ограничен 0.1 с, иначе после паузы или переключения вкладки игрок «телепортируется» на большой шаг.
2. **Этажи и зона.** Видимость групп этажей, текущая зона (имя на экране, эхо, приглушение музыки), триггеры.
3. **Отсечение.** Предметы по расстоянию и закрытым комнатам, раз в 0.1 с.
4. **Свет.** Раздача пула раз в 0.25 с, затухание каждый кадр, рассеянный свет комнаты.
5. **Анимации.** Только тех этажей, что видны: каждая функция помнит, на каком этаже создана.
6. **Звук.** Пять раз в секунду: громкость позиционных петель.
7. **Взгляд.** Луч раз в 80 мс.
8. **Солнце.** Карта теней обновляется по флагу `W.shadowDirty` (двери, шторы, смена этажа) и раз в 0.5 с.
9. **Рендер** в буфер, затем постобработка на экран.

## 4. Мир

### 4.1 Числа

| Величина | Значение | Почему |
|---|---|---|
| Высота этажа `FH` | 4 м | Потолок 3.7 м плюс перекрытие |
| Потолок `CEIL` | 3.7 м | Ниже 3.2 м тесно, выше 4 м пусто |
| Толщина стен `T` | **0.3 м** | При 0.2 м стены «картонные» на торцах дверей и окон |
| Выступ плинтуса и карниза | 2 см (+12 мм за торец) | Иначе торец плинтуса совпадает с торцом стены |
| Проём двери | 1.0 × 2.2 м | Полотно 0.964 × 2.183, заходит под наличник |
| Подоконник | 0.8 м | У лестницы — выше ступеней (≥ 2.15 м от пола пролёта) |
| Радиус игрока | 0.28 м | Проходит в дверь 1 м с запасом |
| Рост глаз | 1.62 м | |
| Шаг вверх | 0.46 м | Выше — нужна лестница |

### 4.2 Стены

```js
wall(axis, c, a0, a1, y0, h, mats, openings, { inside, trim, ceil })
```

- `axis: 'x'` — стена тянется по X на линии `z = c`; `'z'` — по Z на линии `x = c`.
- `mats = { neg, pos, edge }` — отделка стороны с меньшей координатой, с большей и торцов. Торцы, выходящие в коридор, получают отделку коридора (`edge`), а не плитку соседней комнаты.
- Проёмы: `door`/`hole` (от пола), `open` (арка), `gap` (дыра на высоте `sill`), `window`.
- `inside: ±1` — в какую сторону интерьер; нужен для пятен солнца под окнами.

**Правила сборки коробки:**

1. Стены вдоль Z идут на всю длину плюс `T/2` с каждой стороны, а стены вдоль X — **между их внутренними гранями**. На углах тогда нет совпадающих торцов.
2. В Т-образном стыке перегородки и стены коридора **одна стена закрывает торец другой**. Стена коридора доходит до угла (`r.x0 − T/2`), перегородка кончается у её грани. Иначе в углу видна полоска чужой плитки и шов.
3. Стена, доходящая до пола следующего этажа, кончается на 12 мм ниже: её верх не совпадает с полом.
4. Если сдвигаешь толщину стен, **сдвигай расстановку**: мебель «у стены» считается от грани (`ось ± T/2`), а не от оси. Удобно задавать координаты в системе комнаты: `u` вдоль стены от угла, `v` от грани стены вглубь. В отеле так устроен `roomFrame`, и после утолщения стен вся мебель номеров сдвинулась одной правкой.

### 4.3 Перекрытия и проёмы

- Пол и потолок — плоскости. Каждая регистрирует «сплошное» в `W.solids` (для детектора мерцания) и поверхность для ходьбы.
- Пустоту между потолком этажа и полом следующего (≈ 30 см) **закрывай торцом** у каждого проёма: лестничного, атриума, шахты. Иначе сквозь щель над проёмом виден соседний этаж (`stairFascia` в отеле).

### 4.4 Двери

- Полотно на 18 мм уже проёма и заходит под наличник. Никаких просветов по бокам и сверху.
- Перед установкой подумай, **куда ложится открытое полотно**. Если оно закрывает что-то нужное (лаз, выключатель, проход), перевесь петли (`hinge: ±1`) или сдвинь проём (`doorAt`).
- Ставь дверь посередине стены, а не впритык к углу: входить неудобно, если сразу за дверью упираешься в кабинку или шкаф.
- Закрытая дверь прячет вещи комнаты (раздел 12) и глушит звук из неё (раздел 13). Сама дверь при этом **никогда** не прячется.

### 4.5 Окна

- Окно — проём, рама, импосты, подоконники с двух сторон, стекло (почти прозрачное, `noRay` по прозрачности), коллайдер.
- У лестницы подоконник выше ступеней и площадки, иначе марш упирается прямо в стекло.
- Окно регистрируется в `W.windows`: по этому списку строятся пятна солнца.

### 4.6 Лестницы

```js
stairs(x0, z0, x1, z1, y0, y1, '+z', mat)
```

Ступени — блоки, а под ногами гладкий пандус-поверхность. Игрок не прыгает по ступеням, нога поднимается сама.

- **Светильники на лестнице меряются от ступени под ними**, а не от пола этажа: ~2 м над маршем, ~2.3 м над площадкой. На последнем пролёте над площадкой уже пол верхнего этажа: бра вешаются так, чтобы и с этажа выглядели на привычной высоте.
- Зона лестничной клетки получает `shaft: 2.6`: свет и звук проходят по всей шахте, а не обрезаются полом этажа.
- Площадка выше 0.46 м (сцена) — блок **с коллайдером**: сбоку на неё не залезть, только по ступеням.

### 4.7 Зоны

```js
zone(x0, z0, x1, z1, 'ИМЯ', { room, h, shaft, reverb, amb, muffle, lightsFrom, noSun, seeThrough })
```

Зона — комната. От неё зависят имя на экране, эхо, приглушение музыки, рассеянный свет, **граница света ламп**, глушение звука, выключатели, отсечение закрытых комнат.

- Границы проводятся **по осям стен**: тогда внутренняя грань стены освещается своей лампой, а соседняя комната — нет.
- Вложенные зоны допустимы: выигрывает наименьшая, в которую попала точка.
- `room: true` — закрываемая комната (вещи прячутся за закрытой дверью); `seeThrough: true` — отсюда видны другие этажи (лестница, атриум); `lightsFrom: [зоны]` — чьи лампы светят сюда с другого этажа (окно холла во двусветный вестибюль).

## 5. Мерцание (z-fighting)

Симптом: текстуры «рябят» и «съедаются», особенно на потолке, у плинтусов, на картинах, на ребре угла. Причина почти всегда одна: **две видимые поверхности в одной плоскости**.

**Правила:**

| Ситуация | Как правильно |
|---|---|
| Картина, табличка, записка на стене | Подложка от стены, изображение на 14–32 мм впереди; сама группа на 3–4 мм от грани стены |
| Ковёр, пятно солнца, ореол | `polygonOffset` (`decalMat`) или 1 см над полом |
| Плинтус, карниз | Выступают на 2 см, концы — на 12 мм дальше торца стены |
| Стена под полом следующего этажа | Верх на 12 мм ниже пола |
| Наличник двери | Выступает из стены на 4 см |
| Парапет/карниз фасада | Не доходит до внутренней грани стены (утоплен в стену) |
| Стопка одинаковых плит, ящики шкафа | Детали на ≥ 4–6 мм впереди корпуса, не «вровень» |
| Пол сцены/бассейна поверх пола | Боковины чуть ниже (на 2 см), а не до той же высоты |

**Детектор:** `__qaCoplanar()` ищет пары видимых осевых граней ближе 6 мм, которые перекрываются. Он отбрасывает грани, спрятанные внутри «сплошного» (`W.solids`), низы на уровне пола и верхи под следующим этажом. Цель — 0 групп в местах, куда может попасть игрок.

## 6. Физика игрока

- **Коллизии.** Цилиндр радиуса 0.28 против AABB-коллайдеров. В плане XZ это окружность против прямоугольника, по высоте учитываются только коробки между коленом (+0.3) и макушкой (+1.75). Три итерации выталкивания.
- **Подшаги.** Движение кадра дробится на куски по 12 см: на 10 FPS игрок не проходит сквозь стену толщиной 0.3.
- **Пол.** Высота — максимум из поверхностей под точкой не выше `y + 0.46`. Если под новой точкой нет ни одной поверхности, туда шагнуть нельзя: так игрок не выходит в пустоту за край мира.
- **Гравитация** 22 м/с², страховка: провалился ниже −50 — на точку старта. Для комнат вне плана (раздел 16) страховку отключай.
- **Скорость** 2.5 м/с шаг, 4.6 бег, инерция ~0.1 с (`lerp` к желаемой скорости).
- **Покачивание и шаги.** Фаза покачивания растёт со скоростью; на каждом полупериоде — звук шага по материалу поверхности (`sound` у пола).
- **Сидение.** Камера переезжает в точку над сиденьем, взгляд ограничен ±1.6 рад от направления сиденья. Встать — движением (через 0.6 с) или пробелом.
- **Телепорт** — с затемнением (`fadeTo`) и блокировкой ввода (`state.busy`) на время перехода.

## 7. Взаимодействие

```js
interact(obj, labelOrFn, action)
```

- Луч из центра экрана длиной 2.6 м раз в 80 мс. Решает первое попадание: стена перед предметом его закрывает.
- Пропускаются `noRay` (наклейки, вода, ореолы), аддитивные материалы и почти прозрачное стекло.
- У мелких предметов — невидимый `hitBox` побольше: центром экрана в спичечный коробок не попасть.
- Подпись может быть функцией: «Открыть / Закрыть», «Включить / Выключить свет».
- **Двухшаговые действия разделяй на разные объекты.** Например, лаз: «Плитка шатается…» на плитке, затем «Пролезть в лаз» на проёме. И проверь, что открытая дверь не перехватывает луч к ним.
- Для тестов и скриптов: `findInteract(/подпись/, рядом_с)` и `__game.act(/подпись/)`.

## 8. Предметы и расстановка

- Предмет — группа: `(x, z)` на полу этажа, `ry` — поворот, локальная +Z — «лицо». Стул смотрит туда, куда смотрит сидящий, телевизор — экраном.
- Каждый предмет помечает, на чём держится: `mount(g, 'floor' | 'table' | 'wall' | 'ceiling' | 'support')`. По этим меткам `__qa()` ловит висящее в воздухе, не прилегающее к стене и торчащее в стену.
- То, на что ставят (стол, комод), хранит высоту `userData.top`; ставь сверху через `top(g, lx, lz)`.
- Коллайдер — `solid(g, w, d, h)`, с учётом поворота.
- **Логика вещей:**
  - Монитор смотрит на кресло, а не на дверь.
  - У стола есть место, где сидеть: стол у стены, стул с другой стороны, проход ≥ 0.8 м.
  - Телевизор не закрывает окно.
  - Растения не ближе 0.6 м к стене: листья торчат во все стороны.
  - На сдвижной панели (тайный вход) ничего не висит, иначе после сдвига бра повиснет в воздухе.
  - Полки «полные», если это библиотека или кабинет; пустые — только если это сюжет.
- **Логика мира.** Подумай, где солнце. Окна на теневую сторону не дают пятен, и записка «смотрю на солнце» в северной комнате — ошибка лора (раздел 16).

## 9. Свет ламп

### 9.1 Пул

Ламп в мире сотни (`anchor`), настоящих `PointLight` — 10. Раз в 0.25 с:

1. Кандидаты: включённые, с током, на своём этаже (или из `lightsFrom`), не дальше `distance + 10`. Ранг — расстояние минус яркость × 0.25.
2. Первые 10 — «нужные», следующие 3 — «запас» (их не выгоняют, чтобы не было мерцания на границе).
3. Лишние гаснут плавно (2.5/с), новые плавно зажигаются.
4. **Если свободного источника нет, его забирают у гаснущего или у лампы из запаса.** Без этого включённая заново лампа не загоралась, пока игрок не отойдёт.

### 9.2 Свет только в своей комнате

Шейдер three.js патчится: вклад каждого точечного источника умножается на маску «точка внутри коробки зоны лампы» (`lights_fragment_begin`). Коробка = прямоугольник зоны × высота зоны (`h`, у лестницы плюс `shaft`). Итог: свет не проходит сквозь стены, коридорное бра не освещает номер.

Следствие: в открытых пространствах (арка между залами) свет на стыке тоже обрывается. Если это мешает, объедини такие залы в одну зону или задай `open: true`.

### 9.3 Видимое состояние лампы

```js
lampVis(anchor, [плафоны], матВкл, матВыкл, extra)
```

Плафон светится, только если лампа включена **и** есть ток. `a.setOn(v)` — выключатель, `a.refresh()` — после рубильника. Ореол бра прячется вместе с лампой, и ему ставится `userData.off`. Без флага отсечение включало ореол обратно: плафон серый, а пятно на стене светится.

### 9.4 Выключатели

`addLightSwitches()` вызывается после постройки мира и сам расставляет выключатели во **всех** комнатах с верхним светом (`switchable`-лампы в зоне):

- у двери, со стороны ручки, на 1.2 м; если там угол, с другой стороны;
- в комнатах без дверей — у края проёма;
- проверяется, что за местом настоящая стена (не окно, не дверь), место не занято картиной и не загорожено мебелью;
- грань берётся у настоящего блока стены, а не у оси зоны: границы зон и стены иногда расходятся.

`onClicks(zone, n)` — пасхалки на «много щелчков подряд» (пауза между нажатиями < 2.5 с). Если вернуть `true`, свет не переключится.

### 9.5 Рубильник и рассеянный свет

- `setBlackout(true)` гасит все лампы сети (`grid: true`) и их плафоны; свечи, камин и экраны (`grid: false`) горят. После включения лампы возвращаются в положения своих выключателей.
- Если щёлкнуть выключателем при выключенном рубильнике — подсказка (`W.onDeadSwitch`).
- Рассеянный свет комнаты: `zone.amb` × множители. Задёрнутые шторы — до −62 %, погашенный верхний свет — −40 %. Иначе в «тёмной» комнате всё видно, а картины будто светятся.
- **Картины без собственного свечения.** `emissive` у картины выглядит красиво при свете, но в выключенной комнате картина горит, как экран.

## 10. Солнце и тени

Два режима, настройка «тени»; **никогда оба сразу**.

**Тени включены.** Направленный свет с картой теней 4096×2048:

- Камера тени охватывает **всё здание** (`bounds`), а не область вокруг игрока. Тогда тени не «плывут» при ходьбе, а карту можно обновлять редко: по `W.shadowDirty` (двери, шторы, смена этажа) и раз в 0.5 с.
- Свет падает под 22°, хотя видимое солнце ниже (9°). Иначе пятна на полу почти не видны.
- Тень отбрасывают только непрозрачные меши; принимают — освещаемые материалы. `bias −0.0003`, `normalBias 0.008`.
- Внутри помещений интенсивность ≈ 13, на крыше ≈ 2.4 (там светло и без того).
- **Шторы** висят в 16 см от стены и заходят за края окна на 45 см. Косые лучи низкого солнца иначе проскальзывают в щель и рисуют полосы на боковой стене при задёрнутых шторах.

**Тени выключены** (телефоны, слабые видеокарты). Мягкие пятна под окнами:

- **Только у окон, которые смотрят на солнце** (скалярное произведение нормали окна и хода лучей > 0.2). На северных окнах пятен нет.
- Пятно скошено по ходу лучей, гаснет вглубь комнаты, внутри — размытые тени переплётов и поперечины.
- Задёрнутая штора гасит пятно своего окна: флаг `off`, отсечение его не вернёт.

## 11. Постобработка

```text
сцена → буфер HalfFloat (линейный свет) + глубина
     → SSAO по глубине (14 выборок, радиус 1 м, квадрат результата, сила 0.85)
     → тон-кривая (до 0.8 линейно, выше — мягкое насыщение), экспозиция 1.12
     → sRGB вручную
     → [пиксели] 5 бит на канал + дизеринг Байера 4×4 по пикселю буфера
     → виньетка
```

- **Пиксельный режим:** буфер высотой 360 px без сглаживания, растянутый на экран. Это «старая приставка», а не размытие.
- **SSAO** даёт объём, прижимает мебель к полу и затемняет стыки стен. Шум выборок прячется в дизеринг.
- `renderer.toneMapping = NoToneMapping`: тон и sRGB делаем сами, иначе всё пересвечено.
- **Прогрев:** при загрузке все объекты делаются видимыми и материалы компилируются (`warmup`). Без этого игра дёргается, когда комната впервые попадает в кадр.
- Светлое пространство-«сон» (комната вне плана) делается не постобработкой, а светом: светящиеся стены (`emissive` ≈ 0.28) и 5 ярких ламп.

## 12. Отсечение и производительность

- **Слияние статики** (`optimize`): тысячи блоков сливаются по материалу в десятки мешей. UV пересчитываются в мировых метрах (`worldUV`), поэтому текстура не растягивается. Не сливаются интерактивные, `noMerge`, прозрачные, `dynamic`, `hitBox`.
- **Этажи:** видны свой и соседние. Анимации невидимых этажей не считаются.
- **Предметы:** уровни «прорисовки».

| Уровень | Свой этаж | Другие этажи | Закрытые комнаты |
|---|---|---|---|
| ближняя (телефоны) | 25 м | 12 м, только из `seeThrough` | прячутся |
| дальняя (по умолчанию) | 45 м | 40 м, только из `seeThrough` | прячутся |
| вся | всё | всё | видны |

- Закрытая комната (`room: true`, все двери закрыты) прячет свои вещи, пока игрок снаружи. **К комнате относится только то, что внутри неё с запасом 0.3 м.** Двери и вещи на стене коридора стоят ровно на границе, и раньше они пропадали вместе с комнатой: двери становились невидимыми.
- **Флаг `off`** — всё, что игра спрятала сама, отсечение не трогает.
- Ориентиры (программный рендер, 400×250): коридор ~260–350 вызовов отрисовки, большой зал ~400–500, весь этаж без отсечения ~1300.

## 13. Звук

- **Шины:** музыка (через фильтр приглушения), эффекты (с посылом на эхо), окружение (ветер, гул — без эха). У музыки и у звуков отдельные ползунки, значения запоминаются.
- **Эхо комнаты:** одна свёртка, посыл задаёт `zone.reverb` (0.05 кладовка — 1.0 бальный зал). Музыка приглушается фильтром `zone.muffle` (подвал ~1100 Гц).
- **Эффекты** — шум и тон с огибающей: шаги по материалу (ковёр, дерево, мрамор, плитка, бетон, вода), двери, замок, щелчок, выключатель, бумага, шторы, находка.
- **Позиционные петли** (`soundSpot`: вода, телевизор, телефон):
  - громкость `(1 − d/range)^1.5 × gain × стены`; стены: та же комната ×1, соседняя ×0.25, за закрытой дверью ×0.06;
  - **петля начинается с тишины** и не перезапускается на границе слышимости. Затихает до нуля и живёт ещё 6 с. Иначе при ходьбе по коридору «шипит заново» у каждой двери;
  - телефон на ресепшене — `anyLevel`: слышен на других этажах, на 6 м «дальше» за каждый этаж.
- **Гул ламп-трубок** — одна общая петля, громкость по ближайшей включённой трубке.
- **Музыка:** `setMusic(fn, такт)`; `fn(t, i, ctx, out)` планирует такт заранее, на 1.5 с вперёд. Готовый `padMusic(аккорды)`. Смена настроения (сон, другое место) — подмена функции такта с остановкой текущих голосов.
- Браузер не даёт звуку стартовать сам: `initAudio()` — из клика. В Electron ограничение снимается флагом, и музыка играет с титульного экрана.

## 14. Ввод

- **Esc — единственная пауза.** Уход на другую вкладку, Alt+Tab, всплывшее окно — **не пауза**: игра ждёт, при возврате камера сразу слушается мыши («свободный взгляд», курсор спрятан). Захват тихо восстанавливается от первой клавиши или клика: браузер разрешает захват только в ответ на действие человека.
- Первый `mousemove` после захвата — скачок к центру окна; его пропускаем (150 мс и флаг «только что захвачено»).
- При уходе все клавиши отпускаются, иначе зажатая W «залипает».
- Если захват не работает вовсе (встроенные окна, некоторые браузеры), обзор переключается на зажатую кнопку мыши.
- F11 обрабатывается до проверки «игра начата»: работает и в меню.
- Тач: левая часть экрана — стик, правая — обзор, короткий тап — действие.

## 15. Интерфейс и настройки

- **Подсказка действия** `[E] …` внизу по центру; прицел-точка увеличивается на интерактивном.
- **Сообщения** вверху (тосты), **субтитры** внизу, **имя комнаты** при входе.
- **Записки** — бумага с наклоном 0.6°, моноширинный шрифт. В окне записки **нет горизонтальной прокрутки** (`overflow-x: hidden` + отступ): наклонённый листок иначе даёт полосы, даже когда текст влезает.
- **Журнал** собирает записки по историям (`story`), показывает «найдено n из N».
- **Настройки** (меню): музыка, звуки, мышь, пиксели, интерфейс, тени, прорисовка. Все сохраняются (`bindSetting` → localStorage, с защитой от запрета хранилища).
- **Без интерфейса** (H): прячутся счётчики, имя комнаты, прицел, памятка. Подсказки действий, сообщения и субтитры остаются: без них в игру не поиграть.
- **Во весь экран / В окне** и **Выйти** (только в настольной версии).
- Палитра — переменные `:root` в `template.html`.

## 16. Нарратив, лор, пасхалки

**Как рассказывать:**

- Историю рассказывают вещи и записки, а не персонажи. Пустое место сильнее населённого: фигуры людей (манекены, портье) разрушают ощущение «здесь никого нет». Если персонаж нужен, пусть он будет за кадром: голос, письмо, жалоба на него.
- Истории дробятся на 5–8 записок, разбросанных по разным местам. Журнал показывает прогресс, и это само по себе мотивация.
- Записки короткие: 3–8 строк. Последняя строка — поворот или тихая странность («Отражение не садится»).
- Компьютеры с файлами, письма, накладные, жалобы, программки, сет-листы, открытки, спичечные коробки — дешёвые и разнообразные носители текста.

**Логика мира:**

- **Стороны света.** Солнце светит с одной стороны. Окна на теневую сторону — без солнца. Лор комнаты должен с этим совпадать. Пример: северная комната, где гость «смотрит на солнце», превратилась в комнату, где солнце видно только в зеркале.
- Вещи гостей связаны между собой: трофеи в кабинете — с фотографией в ресторане, жалоба — с номером того же гостя.
- **Таблички:** главная строка (заведения — на языке места, например «Restaurant « Le Mirage »») и мелкая строка с переводами.
- **Стиль письма как приём:** письма героя дореформенной орфографией (ѣ, і, ъ), записки разных людей — разными голосами.
- **Чужие тексты** (философия, священные тексты): канонический перевод цитируется точно (синодальный перевод), остальное — пересказ и конспект своими словами с указанием автора. Выдуманное за цитату не выдаётся.
- **Картины:** если нет своих изображений, процедурные «обложки» (штрих в два цвета, арки, сетка, барханы) лучше мемов и схем. Каждый сюжет уникален, без надписей, с названием и подписью.

**Пасхалки:**

- Скрытое действие, которое невозможно сделать случайно, но можно найти: десять быстрых щелчков выключателем, «поправить» картину, отколоть плитку.
- **Подсказка к пасхалке лежит внутри мира** и объясняет её «по-внутриигровому»: записка электрика про тринадцатую линию, которой нет на схеме.
- **Комната вне плана** (сон, иное место) строится далеко от здания (например, на −30 м), без страховки от падения. Вход и выход — телепорт с запоминанием точки и взгляда: возвращение «как будто ничего не было». В ней своя музыка и свой свет, обычно очень светлый.
- Секретный вход: сдвижная панель стены с картиной, лаз за плиткой. Проём — настоящий, в стене (`gap`), а не нарисованное пятно. Отколотая деталь падает рядом, на виду.

## 17. Сборка и выпуск

- `node build.mjs <игра>` → `dist/<Файл>.html`: esbuild собирает код в один IIFE, шаблон получает название, подзаголовок и описание. `DEV=1` — без минификации.
- **Electron** (`desktop/`):
  - запуск во весь экран, F11, кнопка «Выйти»;
  - звук без клика (`autoplay-policy`), `ignore-gpu-blocklist`;
  - одна копия программы, ссылки — в обычном браузере;
  - настройки в `%APPDATA%\<Название>`;
  - игра видит `window.desktop` (`quit`, `toggleFullscreen`, `isFullscreen`, `onFullscreen`) через preload с `contextIsolation`.
- Иконка и сведения о версии вшиваются в exe библиотекой `resedit` (`afterPack`) — **без Wine**, сборка возможна на Linux.
- Переносной exe ~77 МБ. Без подписи кода Windows показывает SmartScreen: «Подробнее → Выполнить в любом случае».

## 19. Журнал граблей

Каждая строка — реальная ошибка из Grand Simulacre.

| Симптом | Причина | Правило |
|---|---|---|
| Мигают текстуры потолка, плинтусов, картин | Совпадающие плоскости: карниз = потолок, картина в 2 мм от стены, торцы | Раздел 5; `__qaCoplanar` после каждой правки |
| Мигает штукатурка под окном в торце коридора | Парапет фасада совпал с внутренней гранью стены после её утолщения | Наружные детали утоплены в стену, а не «вровень» |
| Стены как картон, шов на углу | `T = 0.2`, торец перегородки в коридоре облицован чужой плиткой | `T = 0.3`; одна стена закрывает торец другой; `edge` = отделка коридора |
| После утолщения стен кресла и шкафы торчат в стену | Координаты мебели от оси стены | Координаты от грани (`roomFrame`); `__qa` после изменения `T` |
| Просвет у лестницы на соседний этаж | Нет торца перекрытия у проёма | Торец (fascia) у каждого проёма перекрытия |
| Просвет вокруг двери | Полотно уже коробки | Полотно заходит под наличник |
| Свет ламп проходит сквозь стены | `PointLight` не знает о стенах | Маска коробки зоны в шейдере |
| Свет на лестнице плоский | Одно бра и сильный рассеянный свет | 2–3 источника пятнами, `amb` ниже, шахта `shaft` |
| Бра на лестнице у пола / под потолком | Высота от пола этажа, а не от ступени | Высота от ступени под светильником |
| Выключенный свет не включается | Пул занят соседями, новой лампе не досталось источника | Забирать источник у гаснущей или дальней лампы |
| Погасшее бра оставляет пятно на стене | Отсечение включало ореол обратно | Флаг `userData.off` |
| Картины светятся в тёмной комнате | `emissive` у картины | Без свечения; рассеянный свет падает при погашенных лампах |
