# Отель «Полдень»

Бродилка от первого лица по пустому отелю: low-poly, тёмная палитра, лиминальные пространства и weirdcore. За окнами — тёмно-малиновая пустыня, тёпло-жёлтое небо и маленькое оранжевое солнце, которое никогда не садится.

**Играть:** открой `dist/Hotel.html` в браузере. Это один файл, в нём код и все картинки, интернет не нужен.

## Что внутри

- **Вестибюль.** Высокий тёмный зал с окнами в пол, колоннами, сухим фонтаном, роялем, стойкой регистрации, залом ожидания и выставкой портретов.
- **Служебное крыло 1-го этажа:** подсобка, кухня, бар «Полдень», мужская и женская уборные, комната персонала, игровой зал с автоматами.
- **Этажи 2–4:** коридоры с зелёным ковром, номера 201–208, 301–308 (вместо 308 — 313), 401–408. Номера разные: обычный, twin, пустой, игровой, кабинет, детский, после вечеринки, фотолаборатория с красным светом, лаунж, номер с телевизорами, затопленный номер.
- **Подвал:** котельная, прачечная, архив, склад мебели, электрощитовая (рубильник гасит свет во всём отеле), разгрузка.
- **Лестница и лифт** между всеми этажами.

Картинки (125 штук) висят в рамах, в каждом номере свои, повторов нет. Источники: `Pictures.zip`, `Art.zip/Other` и `weirdcore_y2k_100.zip`. Работы Кары Эклунд и Саяки Канамори не используются. Если подойти к картине и нажать E, откроется крупный вид с автором и лицензией (для фото из Flickr/Openverse — из `CREDITS.txt`).

## Взаимодействия

Стаканы и бутылки звенят. На стульях, креслах, диванах и у рояля можно сидеть, на кроватях — лежать. Двери открываются со скрипом, часть заперта (а за одной кто-то стучит в ответ). Ещё есть лампы и торшеры, телевизоры с помехами, телефоны с сообщениями, краны, унитазы, шторы, стиральные машины, торговые автоматы, звонок на ресепшене, рояль, игровые автоматы, радио (переключает станции музыки), записки, лифт.

## Управление

| | ПК | Телефон |
|---|---|---|
| Идти | WASD / стрелки, Shift — бег | левая половина экрана — джойстик |
| Смотреть | мышь | вести пальцем справа |
| Действие | E или ЛКМ | тап или кнопка E |
| Встать | Пробел или начать идти | кнопка E |
| Фонарик | F | ☀ |
| Музыка / пиксели / пауза | M / P / Esc | II |

## Звук

Звука из файлов нет, всё синтезируется на лету через WebAudio. Музыка — генеративный vaporwave ambient: медленные септаккорды с «плывущей» плёнкой, электропиано с эхом и виниловым треском, три радиостанции. Шаги звучат по-разному на ковре, плитке, мраморе, дереве, бетоне и в воде. Ещё есть двери, лифт, стаканы, смыв, помехи, телефонные гудки. Реверберация меняется от зоны к зоне.

## Сборка

```bash
npm install
npm run build        # -> dist/Hotel.html
```

Код лежит в `src/`: `hotel.js` — планировка, `props.js` — мебель, `engine.js` — стены, окна, двери, коллизии, `sky.js` — небо и пустыня, `audio.js` — звук, `main.js` — игрок и интерфейс. Скрипт `tools/prepare_images.py` пересобирает `assets/img` и `src/images.json` из архивов в корне репозитория.
